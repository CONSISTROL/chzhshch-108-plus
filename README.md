## Web 电子书（推荐阅读方式）

用浏览器直接打开 [`web/ebook.html`](web/ebook.html) 即可阅读，**单个文件、完全离线、无需联网也无需安装任何东西**：

| 内容 | 数量 |
| --- | --- |
| 课文 | 108 课 |
| 文章总数（含解盘、补充文） | 113 篇 |
| 课后回复 | 2624 条 |
| 原文配图（base64 内嵌） | 43 张 |
| 正文 | 约 25.2 万字 |
| 单文件体积 | 约 9.4 MB |

已实现的功能：

- **全文搜索**：跨课文正文与课后回复检索，命中词在结果与正文中高亮；快捷键 `/` 或 `Ctrl/⌘ + K`
- **分类目录**：课文 108 / 解盘·补充文 两组，标示已读进度，支持按类型筛选
- **课后回复折叠**：默认收起，一键展开；疑似缠师的回复单独标记（红框 + 「缠师」标签）
- **深色模式 / 字号调节**：A− A A+ A++ 四档字号
- **阅读进度记忆**：记录每篇的滚动位置、主题、字号与回复展开状态，下次打开自动恢复
- **键盘翻页**：`←` `→` 上下篇，`C` 展开/收起回复，`T` 切换主题，`Esc` 关闭浮层
- **配图灯箱**：点击放大、再点还原
- **移动端适配**：抽屉式目录，手机浏览器可直接阅读；支持打印/另存为 PDF 样式

因为这个文件可以独立存在，可以直接发给别人，或拷到手机、平板、U 盘里离线阅读。

### 重新构建电子书

修改 `108/` 下的原文后，重新生成为单文件电子书：

```bash
npm run build          # 等价于 node build-web-ebook.js
```

构建脚本会读取全部 `108/*.md` 与 `108/pic/` 配图，解析课文、课后回复、日期分类，把配图转成 base64 内嵌，再套用 `web/template.html` 模板输出 `web/ebook.html`。

### 自检

```bash
npm run verify         # 结构自检：文章/课文/回复/配图数量、序号连续性、markdown 残留
npm run smoke          # 浏览器冒烟测试：渲染、搜索、折叠、主题、进度记忆、翻页、移动端布局
```

`npm run smoke` 需要本机装有 Chrome 或 Edge（可用 `CHROME_PATH` 指定路径），会自动启动无头浏览器逐项断言，并把截图输出到系统临时目录。

### 合并为单个 Markdown

```bash
npm run merge          # 生成 108/108-All.md 与 108/108-artileOnly.md
```
